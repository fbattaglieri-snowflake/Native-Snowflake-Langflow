Flows that start on their own

Four triggers start a flow from inside Snowflake. Each one creates the Snowflake object it needs, so there is nothing to set up by hand.

ScheduleEvery morning, every hour, any cron. Creates a task.
Table changeWhen rows are inserted, updated or deleted. Creates a stream and a task.
Stage fileWhen a file lands on a stage. Creates a directory table, a stream and a task.
Condition alertWhen a SQL condition returns rows. Creates an alert.

Your data and your own logic, one drag away

Six data sources

Tables, views, Iceberg tables, Snowflake Postgres, Cortex Search and Cortex Analyst. Each can be switched to Tool Mode for an agent.

Procedures and functions as tools

Custom Tool reads the parameters of a stored procedure or a function and turns it into a tool. Run it directly or hand it to an agent.

SQL with bound values

SQL Statement runs a SELECT or a CALL. Values coming from other nodes are bound, never pasted into the text.

Memory on Snowflake tables

Four memory types and a chat history, all stored in tables, with cleanup on a schedule. More in Benefits
