# ADR-001: Upstream Baseline (`v1.12.5`), `lfx_snowflake` Bundle Isolation & Core Patch Registry

- **Status:** Accepted
- **Date:** 2026-10-17
- **Upstream Baseline:** `langflow-ai/langflow` tag `v1.12.5` (MIT License)

## Context
SnowflakeLangflow must track upstream `langflow-ai/langflow` while delivering deep native Snowflake capabilities (SPCS authentication, active role switching, Proxy Standard 3-protocol integration, governed object provisioning, SQL trace replication) without creating an unmaintainable divergent fork or altering Langflow's visual design system.

## Decision
1. Freeze the initial upstream baseline on `langflow-ai/langflow` `v1.12.5` (MIT License) with protected branch `snowflake/main` and dedicated upgrade branches `sync/upstream-<version>`.
2. Isolate all Snowflake providers, governance services, trace/audit replicators, and custom components inside `src/lfx_snowflake/` (`lfx_snowflake` bundle).
3. Restrict modifications to upstream core (`src/frontend/` and `src/backend/base/langflow/`) to 6 tracked hook points documented in `docs/UPSTREAM_SYNC.md` and `frontend_patches/`.
4. Keep `Input & Output`, `Prompt Template`, `Processing`, `Flow Control` (preserving `[Beta]` badges on `Listen`, `Notify`, `Run Flow`), `LLM Selector`, `Calculator`, and `Current Date` 100% unmodified.

## Consequences
- Upstream merges touch at most the 6 registered hook points.
- Automated non-regression tests verify component and category invariance on every sync.
