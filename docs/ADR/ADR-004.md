# ADR-004: Universal Backend Authorization Enforcement & Explicit 4-Code Error Taxonomy

- **Status:** Accepted
- **Date:** 2026-10-17

## Context
Every action in SnowflakeLangflow (UI, REST API, flow/node execution, Tool Mode, flow import/export, object provisioning, Model/DB Providers, Global Variables, Cortex Analyst, Knowledge, Memories, Python Interpreter, ToolGuard, A2A client/server, and SQL trace queries) must enforce permissions in the backend at execution time without leaking metadata about unauthorized objects or misattributing network/capability failures to role denials.

## Decision
1. **Universal Backend Guard (`require_snowflake_permission`):** Enforce active-role checks on all routes and components, using `EXPLAIN_PRIVILEGES(..., missing_only => true)` for zero-credit pre-flight privilege validation on SQL and AI Functions.
2. **Mandatory 4-Code Error Taxonomy:**
   - `AUTHZ_ROLE_DENIED` (HTTP 403): *"Il ruolo attivo (`<ROLE>`) non consente questa operazione (`<OPERATION>`)"*, surfacing `required_privilege` only when safe to disclose and never leaking restricted object existence.
   - `OBJECT_NOT_FOUND_OR_UNAUTHORIZED` (HTTP 403/404): Preserves Snowflake's exact *"does not exist or not authorized"* boundary without revealing whether a restricted object exists.
   - `UNSUPPORTED_CAPABILITY` (HTTP 422): Unsupported or unqualified combination of model, protocol, storage backend, or function parameter.
   - `TECHNICAL_EXECUTION_ERROR` (HTTP 500/502/504): Upstream network, timeout, SPCS, or database execution failure.
3. **Epoch Invalidation (`context_epoch`):** Every role switch or privilege revocation increments `context_epoch`, immediately flushing all session caches, catalog previews, and `EXPLAIN_PRIVILEGES` caches.

## Consequences
- Zero silent privilege escalation, zero object-existence leaks, and consistent native error banners across UI and API.

## v0.8.6 Update

`/api/v1/snowflake/*` requires Langflow-native authentication (only the A2A agent card may be public). A2A maps errors to JSON-RPC `-32000` (authorization), `-32001` (task not found), `-32002` (not cancelable). Component SQL is blocked fail-closed by the flow `[ ❄️ Context ]` guard.

Tool Mode tools (`AI Function`, `Custom Tool`, data sources) run through the same flow `[ ❄️ Context ]` guard as node execution, and a failing routine fails the tool call. The A2A internal target list is limited to flows served as A2A agents in the caller's project. The `LF_MEM_*` table of a Memory Base attached to a flow is always part of that flow's context.
