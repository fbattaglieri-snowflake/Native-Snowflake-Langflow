What makes a report easy to act on

Five lines are enough. The more of them you can fill in, the faster the problem can be reproduced.

What you were doing

The flow, the node and the question or input you gave it.

What you expected

One sentence is fine.

What happened instead

The message on the node, including the error code if there is one, for example AUTHZ_ROLE_DENIED.

The role and the Context

Which role was selected in the top bar, and whether the object was ticked in the flow Context. Use a placeholder for names you cannot share.

The version

The project version or image tag you are running, and the cloud your Snowflake account is on.
