What it does not do yet

Better to read this before you plan a demo than to find out during one. The full list is in the README.

Language Model and Agent need an LLM proxy

It is a separate service, not part of this repository. Cortex Agent and the AI function nodes do not use it. Details

Not ready for production

It is under active testing. Run your own qualification and security review first.

Tested on AWS only

Other clouds have not been tried.

No file upload from the browser

Load files on a stage with Snowsight or the CLI.

External Volumes are untested

Creation is implemented but has never run against a real bucket.

Queries run as the service

They are limited to the role you select. Running as the signed-in user exists but is off by default.

One instance

The Langflow database sits on a block volume, so the service runs a single replica.

Cortex Analyst returns the full record

Outside Tool Mode the node gives back the API response as JSON, which uses more tokens in a prompt.

Decision ratings vary

In comparisons they are close to each other and change from one run to the next.

Try it, then say what broke

The most useful feedback right now is a flow that did not behave the way you expected, with the question you asked and the role you used.
