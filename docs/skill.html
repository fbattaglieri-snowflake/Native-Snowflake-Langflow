A skill that teaches your coding agent this tool

A folder of instructions and a small client. With it, Cortex Code, Claude Code or another coding agent can build a flow from a sentence, set its role and Context, run it, read every node and fix what fails.

01

Get the folder

It is in the repository, under skills/native-snowflake-langflow. Clone the repository or download that folder.

skills/native-snowflake-langflow
02

Give it to your agent

Cortex Code: cortex skill add <path to the folder>. Claude Code: copy the folder into ~/.claude/skills/. Other tools: point the agent at SKILL.md.

03

Set three variables

The service URL, a Langflow API key and a Snowflake access token, as environment variables in your shell. The skill never asks you to paste them in the chat.

What you can ask

The agent discovers the nodes on your server, picks a pattern, builds the flow as code and runs it. You open the result in the canvas.

Ask in plain words
Build a flow that removes personal data from a ticket, classifies the fault and asks my Cortex Agent for advice. Use the role ANALYST.
My flow "Inbox to tickets" fails on the fourth node. Find out why and fix it.
I have a Cortex Agent that needs a job that takes minutes. Set up a flow it can start and wait for.
Export the flow "Weekly plan" to a file I can share.
What is in the folder
SKILL.mdThe rules: role, Context, proxy, and the order of work
scripts/lf.pyThe client: list nodes, build, save, run, export. Python standard library only
references/nodes.mdField names and output ports of the common nodes
references/patterns.mdFive design patterns with code that was run against a live service
references/troubleshooting.mdError messages, causes and fixes

The same client, by hand

The skill is not required to use the client. These commands work from any terminal once the three variables are set.

python3 scripts/lf.py check                      # is the service reachable, which models does the proxy serve
python3 scripts/lf.py nodes snowflake            # the Snowflake nodes installed
python3 scripts/lf.py node SnowflakeSQLStatement # fields and output ports of one node
python3 scripts/lf.py import 2_sequential_redact_classify_agent.json
python3 scripts/lf.py role "EXAMPLE_2_Sequential_Redact_Classify_Cortex_Agent" MY_ROLE
python3 scripts/lf.py run  "EXAMPLE_2_Sequential_Redact_Classify_Cortex_Agent" "Chiller C7 is leaking coolant"
What was testedThe five patterns run end to end with this client on the test service. Cortex Code found the skill after cortex skill add. Using it in a conversation, and loading it in Claude Code or other tools, was not tested.
It builds flows, not Snowflake objectsTables, search services and agents must exist already. The examples come with a script that creates theirs.
Same limits as the editorA flow built by an agent runs under the role and the Context you give it, like any other flow.
