Three starter examples you can rebuild

Small flows on the same sample data: a maintenance team with tickets, procedures and a Cortex Agent. One SQL script creates every object they need.

01

Run one SQL script

It creates a schema with tables, a semantic view, a Cortex Search service, a Cortex Agent, a function and a procedure. Run it again to start over.

00_setup.sql
02

Import the flows

Upload the three flow files in Langflow. Each one opens ready to run, with its nodes already configured.

examples/maintenance
03

Pick a role and a Context

Select a role that can read the schema, then select the schema EXAMPLES in the flow Context. Run.

Example 1 · parallel

Two helpers, one Cortex Agent

Two helpers work on the same question at the same time, each in its own way and on its own model. A Cortex Agent reads both results and writes the answer.

Example 3 · data engineering

Inbox to tickets

No chat. Raw messages land in a table and each run turns the oldest one into a clean ticket, using SQL, an AI function, a Decision, a stored procedure and a SQL function.

A raw message
TORINO - the light curtain on press A12 did not react twice this morning. Operators are worried.

Works without the LLM proxy

The ticket it becomes
SiteTORINO_PLANT · function NORMALIZE_SITE
AssetPRESS_A12 · AI_EXTRACT
Severityhigh · Decision
Written byprocedure LOAD_TICKET

One message per run: run it four times to empty the sample inbox. The trigger is saved paused, so nothing runs on its own until you activate it.

Four larger flows, as ideas

Richer flows from my own tests: memory, agents in a row, approaches compared by a Decision node. They are not shipped with a setup script. They run on synthetic maintenance and warranty data, and three of them need the LLM proxy.

A language model becomes an agent with every memory type

A language model gets Cortex Analyst and Cortex Search as tools, plus summary, profile and episodic memory stored in Snowflake tables.

Chat InputLanguage ModelAnalyst + SearchAgent MemoryChat Output
  • Turn 1 uses Analyst for a count, turn 2 uses Search for a procedure
  • Turn 3 saves an outcome that worked
  • In a new chat it still knows the site and the fix

Needs the LLM proxy: it uses Language Model

turn 3I replaced the shaft seal kit and the leak test passed. That worked.
new chatWhich site do I work at, and do we know a fix that worked for a chiller coolant leak?

Two Cortex Agents in sequence

The first agent answers with numbers from warranty data. Its answer is passed to a second agent that reads the technical documentation.
