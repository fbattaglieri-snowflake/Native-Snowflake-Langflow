Four flows to try

Each one starts with a chat input and ends with a chat output. They run on synthetic maintenance and warranty data. Three of them need the LLM proxy.

A language model becomes an agent with every memory type

A language model gets Cortex Analyst and Cortex Search as tools, plus summary, profile and episodic memory stored in Snowflake tables.

Chat InputLanguage ModelAnalyst + SearchAgent MemoryChat Output
  • Turn 1 uses Analyst for a count, turn 2 uses Search for a procedure
  • Turn 3 saves an outcome that worked
  • In a new chat it still knows the site and the fix

Needs the LLM proxy: it uses Language Model

DEMO_Language_Model_As_Agent_With_Every_Memory_Type

Ask, in this order
turn 1I am Marco, maintenance lead at MILANO_PLANT. How many open tickets does my site have?
turn 2Chiller C7 is leaking coolant. What does the procedure say?
turn 3I replaced the shaft seal kit and the leak test passed. That worked.
new chatWhich site do I work at, and do we know a fix that worked for a chiller coolant leak?

Two Cortex Agents in sequence

The first agent answers with numbers from warranty data. Its answer is passed to a second agent that reads the technical documentation.

Chat InputCortex Agent · warrantyCortex Agent · tech docsChat Output
  • The numbers match a direct SQL query: 154 claims, total cost 441,587
  • The second answer refers to the component named by the first
  • A Cortex Agent response also shows the text it writes before calling tools

Works without the LLM proxy: both steps are Cortex Agents

DEMO_Two_Cortex_Agents_In_Sequence

Ask
How many warranty claims does the hydraulic pump have and what do they cost? Then tell me what the technical documentation says about that component.

Language model against Cortex Agent, judged by Decision

A language model with an AI function and a Cortex Agent answer the same question. A Decision node picks one, and a language model explains why.

Chat InputLanguage Model + AI FunctionCortex AgentDecisionChat Output
  • Which of the two answers Decision chose
  • The explanation the language model gives for that choice

Needs the LLM proxy: it uses Language Model

DEMO_Language_Model_Vs_Cortex_Agent_Judged_By_Decision

Ask
Chiller C7 at MILANO_PLANT is leaking coolant and the line is stopped. What should the technician do?

Cortex Agent, Agent with tools and Language Model, rated 0 to 4

One question goes to three approaches at once. Each keeps its own memory, and a Decision node rates every answer.

Chat InputCortex AgentAgentLanguage ModelDecisionChat Output
  • Three answers with a rating each
  • The follow-up shows that all three remember the first turn
  • Ratings sit close together and change between runs: read them as a hint, not a measure

Needs the LLM proxy: it uses Agent and Language Model
