Where the model calls go

Language Model and Agent do not call a model directly. They talk to an LLM proxy, a separate service that runs next to Langflow in Snowpark Container Services. It is not part of this repository: you deploy it once and point Langflow at it.

Two editions, one interface

Both are public, MIT licensed and kept in step with each other. Langflow is configured the same way for either: the endpoints, the model list and the request handling are identical.

snowflake-proxy-cortexrestapi

Proxy for the Cortex REST API

  • Forwards to the Cortex REST API
  • Chat, Responses and Messages endpoints
  • Daily check for new and retired models

snowflake-proxy-cortex-aigateway

  • Traces you can query with SQL, joined across client and server

Why there is a proxy at all

Tools like Langflow send requests the way the OpenAI and Anthropic libraries do. Cortex is stricter about some details and rejects them. The proxy rewrites those details on the way through, so the flow keeps working.

No API keys in Langflow

The proxy signs each request with the service token that SPCS rotates for it.

Only models that passed

Each endpoint lists the models qualified for that protocol, so the dropdown in the node shows what works.

Streams in a stable order

Streaming events on the Responses endpoint are put in order before they reach the client.

New models arrive on their own

A daily task compares the models in the account with the day before. A new one is tested before anyone can pick it, and a retired one is withdrawn.

Connect Langflow to the proxy

Deploy one edition from its repository, then set two values in the Langflow service specification.

Deploy the proxy

Follow the README of the edition you chose. It runs as its own service in Snowpark Container Services.

Point Langflow at it

Set the proxy address and allow its host name.

LLM_PROXY_BASE_URL: "http://<PROXY_SERVICE>.<DNS_NAMESPACE>:8080"
LANGFLOW_SSRF_ALLOWED_HOSTS: "<LLM_PROXY_HOST>,localhost,127.0.0.1"

Pick a model

Open a Language Model or Agent node and choose a Snowflake Proxy provider. The model list is read from the proxy.

Private modelsOllama hosted in SPCS is a second provider for the same two nodes, set with OLLAMA_BASE_URL.
